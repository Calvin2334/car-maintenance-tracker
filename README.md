🚗 Car Maintenance Tracker System

A full-stack web application built using PHP, MySQL, HTML, CSS, and XAMPP that allows customers to book car maintenance appointments and enables administrators to manage, assign, and update service requests in real time.

🔧 Features
Customer registration and login system
Book and manage maintenance appointments
Admin dashboard for managing all bookings
Assign services and update appointment status
Cancel and track appointments
Session-based authentication for security
Fully integrated MySQL database using phpMyAdmin
💡 Tech Stack
Frontend: HTML, CSS
Backend: PHP
Database: MySQL (XAMPP / phpMyAdmin)
Local Server: Apache (XAMPP)
